# FusionMark 荧光图快速标注

一个纯浏览器荧光图标注工具。选择箭头或圆圈后，单击细胞融合位置即可连续放置标记；拖动可以自定义箭头方向或圆圈大小。

在线使用：<https://weigenwu.github.io/ygbj/>

## 使用

1. 打开网站并一次添加一张或多张 TIFF、PNG、JPG 或 WebP 图片；也可以在 PowerPoint 中复制图片，然后回到网页按 `Ctrl+V`（macOS 为 `⌘V`）直接粘贴。
2. 默认是箭头工具：单击放置，或从箭尾沿箭头方向拖动。切换圆圈后，单击放置，拖动指定半径。
3. 用“选择”工具移动、调整或删除标记。
4. 在“分屏对照”中选择 1–4 屏；每个对照屏可独立选图，点击“编辑此图”与主屏交换后继续标注。
5. 点击“复制到 PPT”把当前主屏的原分辨率标注图写入剪贴板，回到 PowerPoint 后直接粘贴。
6. 点击“下载 PNG”按原图分辨率导出，或用“下载并下一张”连续处理图片。

快捷键：`A` 箭头、`C` 圆圈、`V` 选择、`H` 移动画布、`Ctrl+Z` 撤销、`Delete` 删除、`0` 适应窗口、`E` 下载。

## 隐私与数据

- 图片解码、标注和导出全部在当前浏览器本地完成，不会上传到服务器。
- 原始图片不会被修改或覆盖。
- 标注坐标会自动保存在当前浏览器的本地存储中；重新选择同一文件可恢复标注。
- TIFF 显示用于人工标注和导出副本，不替代科研原始数据存档。

## 本地运行

无需构建。可以直接打开 `index.html`，或在项目目录执行：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 第三方组件

TIFF 解码使用 MIT 许可的 [UTIF.js](https://github.com/photopea/UTIF.js) 和 [pako](https://github.com/nodeca/pako)，代码随网站一起提供，因此页面运行时不依赖第三方 CDN。
